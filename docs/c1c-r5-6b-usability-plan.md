## Existing contracts and implementation order

1. Route graphical commits and inspector selection through `CadCanvas.tsx`, `App.tsx`, `FoundationWorkspace.tsx` and `FoundationAssemblyPanel.tsx`. Use `foundationAssemblyController.ts` for create, preview, validated Apply and history. Keep adoption explicitly available for existing independent entities. Reuse the existing dimension input and unit parser. Start with UI changes that require no persistence changes.
2. Extend `foundationSnap.ts` with scoped alignment and interior-face targets, using the nearby/angle/grid behavior in `CadCanvas.getSmartSnapPoint` and the existing orthogonal wall perimeter geometry. Keep tool-specific priorities and use existing correction transactions. Add committed rendering and visibility changes in the canvas and assembly inspector, independent of the measurement graph.
3. Resolve standard relationship inputs at the assembly specification/regeneration boundary, using `foundationAssemblyModel.ts`, `foundationAssemblyValidation.ts` and `foundationAssemblyRegeneration.ts`. Regeneration currently needs confirmed wall datum and dimensions. Strip derivation requires a confirmed wall centreline and base and places its top at that base. Exterior derivation requires a compatible wall set with confirmed common elevations and supported coverage. Under-slab derivation requires a confirmed slab reference and computed vertical position. Supply canonical values derived from explicitly confirmed standard relationships before passing them to the existing engines. Preserve their constraints, including unsupported offsets around connected perimeters and manual coverage for complex openings or steps. A geometry offset used only for visual differentiation must have zero impact on coverage and takeoff.
4. Exercise overlap and source-dependency validation through the existing measurement, layer and topology contracts. Treat separate local zeros as comparable only with a confirmed shared reference. Retain valid independent quantities and surface unresolved or invalid contributions according to existing validation. Review any persistence amendment before coding it, preserve schema v3, and leave older records readable without reinterpretation. Preserve atomic Preview, Apply, undo, redo, export and reopen, including detachment and subsequent adoption.
5. Run focused browser tests for the standard workflow and targeted geometry/persistence regressions for the relationships. Preserve the 311-test baseline and run the full required validation on the eventual implementation candidate. Owner practical acceptance should repeat the standard rectangle and an actual irregular foundation, including exterior layers, a slab decision, a trace correction, visible footing and a quantity comparison. Independent plan review is complete. The authorized implementation remains gated at independent source review and targeted practical owner acceptance.

## Footing visibility reproduction

One targeted Chromium test passed on the exact candidate using a synthetic 25 × 20 ft rectangle, 8 in walls and four 24 × 6 in strip footings. It applied sheet waterproofing followed by EPS through the specialist envelope controls. With all components visible, the sampled outer footing stroke was unchanged, and all four serialized footing records remained identical. The waterproofing-only filter hid that stroke and All restored it. The disappearance remains an unresolved owner-reported visual concern. This synthetic check did not reproduce it with All selected. ## Implementation review notes

- The standard perimeter path retains the trace-face choice and exact rectangle correction. **Specify foundation construction** opens a new unsaved coordinated draft directly. The explicit individual-perimeter action remains under Advanced.
- The standard slab relation offers confirmed slab bottom at wall base. A different slab elevation still requires explicit input and compatible reference. Stepped, engineered and unsupported relationships stay in the advanced or independent workflows.
- Confirmed exterior order describes the assembly stack. Each layer continues to use its own confirmed net coverage on the approved measurement face. Canvas styling leaves that geometry unchanged.
- Review pointer feel for axis inference and slab interior snapping on calibrated drawings. Full R5 acceptance remains withheld pending actual-plan review.
